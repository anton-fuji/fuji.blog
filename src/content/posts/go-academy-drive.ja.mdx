CyberAgentさんが主催している「Go Academy Drive」に参加してきました〜。

https://www.cyberagent.co.jp/techinfo/news/detail/id=33590

2026年10月の1ヶ月間、毎週土曜日はGoの日でした。

参加した感想を先に書くと、**めちゃよかったです**。

1ヶ月で何をやったのか、自分にとって何がよかったのかを、熱が冷めないうちにまとめておきます。

## 申し込んだ理由

もともとGoは独学で色々勉強していて、学んだことはZennやQiitaにアウトプットしていました。

独学は、気になったところから好きなだけ掘れるのが楽しいです。
ただ、そのぶん学ぶ順番は自分の興味まかせになります。
書けるようにはなってきたけど、Goを順を追って説明できるかと聞かれると、ちょっと自信がない。そんな状態でした。

そんなときにGo Academy Driveを知りました。
改めてGoを体系的に学習できる機会がここにある、と思って申し込みました。

## カリキュラムの全体像

カリキュラムはDay1〜Day4の4回構成で、毎週土曜日に授業がありました。

| Day  | 日程         | 内容                               |
| ---- | ------------ | ---------------------------------- |
| Day1 | 10月3日(土)  | Goの開発環境整備とGo言語の仕様理解 |
| Day2 | 10月10日(土) | REST API構築                       |
| Day3 | 10月17日(土) | Goからデータベース接続・操作       |
| Day4 | 10月24日(土) | Webサービス開発 制作物発表会       |

並べてみると、きれいに積み上がる順番になっています。

1. 言語の基本と開発環境を押さえる
2. HTTPでやりとりするAPIを書く
3. データベースにデータを保存して読み出す
4. 全部を組み合わせて1つのWebサービスにして発表する

前の週にやったことが、そのまま次の週の前提になります。
独学だとつまみ食いしがちな部分も、この順番で通して学ぶと、それぞれがどこでつながっているのかが見えやすかったです。

Day1〜3は、Goの基礎的な学習はもちろん、REST APIをGoで実装する方法や、GoでのDB操作の仕方まで丁寧に学習できました。
ここからは1回ずつ振り返っていきます。

## Day1 開発環境とGoの仕様

最初の回は、開発環境を整えるところと、Goの言語仕様の理解からでした。

Goは、開発に必要なツールが標準でかなりそろっている言語です。
モジュール管理の `go mod`、フォーマッタの `go fmt`、テストの `go test`、静的チェックの `go vet` など、だいたいのことは `go` コマンドだけで済みます。

独学で書いてきた身としては、普段なんとなく使っているものを、言語仕様の側からもう一度見直せたのがよかったです。
「たぶんこう動くだろう」で書いていたところが、「仕様でこう決まっているからこう動く」に変わると、コードを書くときの安心感がまったく違います。

## Day2 REST API構築

2回目はREST APIの構築です。

GoでWebのAPIを書くときは、標準ライブラリの `net/http` だけでも、かなりのところまで書けます。
ルーティングを決めて、リクエストを受け取り、JSONを返す。やっていることはシンプルです。

ただ、シンプルだからこそ、ハンドラをどう分けるか、エラーをどう返すかといった設計の部分は自分で考えることになります。
ここは独学でもなんとなく書いていたところでした。授業の流れの中で改めて手を動かすと、自分の書き方の癖にも気づけました。

## Day3 データベース接続・操作

3回目は、Goからデータベースに接続して操作する回でした。

APIを作れても、データを保存できないとWebサービスにはなりません。
Day2で作ったAPIの先に、データベースがつながるイメージです。

Goでは標準の `database/sql` パッケージを入り口に、ドライバを組み合わせてデータベースを扱います。
接続を開く、クエリを投げる、結果を構造体に詰める、エラーを確認する。一つひとつの処理を自分で書くので、何が起きているのかを追いやすいのがGoらしいところだと思っています。

ちょうど少し前に[DBの楽観ロック・悲観ロック](/posts/db-optimistic-pessimistic-locking)の記事を書いていたこともあり、データベースまわりはとくに楽しみにしていた回でした。
